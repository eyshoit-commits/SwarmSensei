## Getting Started
To get started with SwarmSensei:
1. Clone the repository:
   ```sh
   git clone https://github.com/eyshoit-commits/SwarmSensei.git
   ```
2. Navigate to the directory:
   ```sh
   cd SwarmSensei
   ```
3. Install dependencies and build:
   ```sh
   cargo build
   ```
4. Run the project:
   ```sh
   cargo run
   ```
